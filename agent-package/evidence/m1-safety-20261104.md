# M1 safety fixes — evidence (2026-11-04, Claude Code)

Branch `claude/m1-safety-20261104`. Isolated test server on 127.0.0.1 (live agents untouched).

## What changed (agent/agent.py)
- `validate_post()` — deterministic checks: valid account key, format, ISO date
  inside [now−10 min, now+90 days], and results-claim patterns (EN + ES).
  PV only: no clock times in public copy (exact schedule is on the Unknown list).
- Used twice: as the approval gate's `when` predicate (an invalid proposal never
  reaches the owner's card) and inside `propose_post` (it can never be queued).
  The model gets the problem list back and must fix or refuse.
- `DateGroundingMiddleware` — current date, UTC offset and a 7-day calendar on every
  model call; owner-named zones (e.g. UTC) honored.
- `ModelRetryMiddleware` (LangChain built-in) — 429s from the provider are retried
  with backoff, then reported in words. ROOT CAUSE: the "empty reply" failures were
  provider 429s killing runs silently, not the model.
- Prompt: forbidden asks are refused (outranks the propose few-shot); no invented
  client stories (hypotheticals labeled "Example:"); skills are files, not tools;
  plain-text replies, no JSON; public words never carry internal notes.
