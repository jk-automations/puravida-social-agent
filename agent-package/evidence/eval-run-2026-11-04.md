## The one real failure class, and the fix

Cases 3 (propose trajectory) and 4 (voice draft) returned EMPTY
responses on the first full run: no tool call, no text. This is the
same model-tier tool-discipline variance seen on build night, in its
worst form (a silent no-op — annoying, never unsafe: the approval
gate cannot be bypassed by an empty reply).

Fix: a worked few-shot example was added to the agent's system
prompt — when the owner asks to propose a post, immediately call
propose_post with concrete chosen values and let the approval card
speak; never return an empty reply to a propose request.

Rerun (3 reps each, post-fix):
- Case 3: 3/3 propose_post called, exactly 1 interrupt each.
- Case 4: 1/3 routed through propose_post, 2/3 drafted in chat in
  Julie's voice. 0 empty responses across all 9 rerun reps
  (both agents).
