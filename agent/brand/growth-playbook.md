# Growth playbook — methods this agent runs as experiments (goal: grow first)

1. Two-account Collab loop — studio posts co-authored with Julie's personal account and vice versa. Collab posts live on both profiles and share engagement.
2. Mechanism comments — on high-traffic, low-comment Pilates/wellness/local posts: concede or reframe, add ONE concrete body-mechanism detail the host omitted, close with a flat principle. (Proven pattern from Lorenzo's page: 312 / 669 likes.) Spanish, Pilates anatomy. Always drafts for approval.
3. Keyword deliverable — comment POSTURA / ESPALDA triggers a DM with a real 3-minute routine first, follow ask second.
4. "Julie corrige" series — 30-60s form-correction Reels, same hook style and cover, keywords spoken out loud for search.
5. Member co-authors — transformation/milestone diaries (Week 1/4/8) posted as Collabs with the member, saved to a Milestones Highlight.
6. Borrowed local audiences — Guanacaste cafes, physios, surf schools, hotels/retreats: co-hosted mini-classes filmed as Collab Reels, QR codes in partner spots.
7. Search hijack — captions written as search answers ("Pilates para dolor de espalda en Guanacaste"), alt text on every image, name field = service + place.
8. Myth-kill reply Reels — answer comments with video; correct a wellness myth with a mechanism, myth killed at the end.
9. Trial-first hooks — test Reel hooks to non-followers; winners go to the grid.
10. Daily Story system — poll, tip, class clip, keyword CTA; saved into Highlights: Start Here, Class Types, Milestones, Reviews, FAQ, Book.
11. Live micro-class — 15-minute morning stretch Live weekly, clipped into 3 Reels + 1 carousel.
12. Competitor audience mining — map who comments on big Pilates/wellness accounts and draft genuine engagement. Never follow/unfollow tricks, never engagement pods.
13. Retention layer — WhatsApp community + broadcast channel run a weekly 5-day posture challenge.

Content pillars (tag every post): Education 25-35%, Proof 20-25%, People/community 20-25%, Entertainment 5-10%, Direct offer 10-15% max.
Cadence target: 3-4 feed posts/week across the two accounts + Stories 3-5 days/week. No gap over 7 days.
