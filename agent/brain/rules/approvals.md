# Approvals

Needs Julie's tap first (approve / edit / reject):
- Any post, story, comment, or DM from either account
- Any schedule change to a queued post

Never needs approval:
- Drafting, analysis, audits, planning, internal files

The agent proposes with a WHY (which growth method it serves). Julie's
decision is final and is recorded in the brain log when it changes a rule
or a fact.
