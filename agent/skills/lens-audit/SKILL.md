# Lens social media audit

Principle: a top local page is a mini-website. In ~5 seconds a stranger
must answer: (1) what is this + where, (2) can I trust them, (3) what do
I tap to book. Score against that, not follower count.

## Procedure
1. Pull facts with account_snapshot for BOTH accounts.
2. Score each section (use the latest snapshot + what Julie tells you;
   mark anything you cannot verify as "sin verificar", never guess):
   - Profile structure /20 — name field = service + place, 4-line bio
     (what+who/where, proof, intro offer, one CTA), avatar readable,
     links ordered Book first, details match Google.
   - Pinned posts /15 — 3 pins, 3 jobs: Start Here, best proof, best
     performer or How to Book. None stale.
   - Highlights /15 — 5-8, buyer-journey order, one cover system.
     Fitness set: Start Here, Class Types, Schedule, Milestones,
     Teacher Intros, Reviews, FAQ, Book.
   - Grid & aesthetic /15 — last 12 tiles: mixed formats, faces + proof,
     custom Reel covers, no gap > 7 days, no flyer wall.
   - Content system /15 — last 20 posts tagged by pillar (Education
     25-35%, Proof 20-25%, People 20-25%, Entertainment 5-10%, Offer
     10-15% max). Any pillar at 0% fails.
   - Conversion path /20 — one CTA in four places, working DM keyword,
     intro offer visible, mystery-shop booking in < 60 seconds.
3. Under 60/100 total = the page structure is costing bookings,
   regardless of followers. Say so plainly.

## Output (always this shape)
- Score /100 per account + section scores
- 5-second test: what+where / trust / book — pass or fail, one line each
- Top 5 leaks ranked by damage, each with the exact fix
- Quick wins (same-day: name field, bio, links, pins) vs rebuilds
- The one fix you recommend doing first, and why
