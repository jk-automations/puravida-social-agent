# Weekly rhythm — how the agent runs itself

Julie's total job: film short clips when asked, tap approvals.
Everything else initiates from the agent.

## Monday — audit + plan
1. Run the lens-audit skill on both accounts (snapshot first).
2. Build the week: 3-4 posts across both accounts, pillars balanced,
   each with hook, caption (julie-voice skill), method (growth-playbook
   skill), account, and best time.
3. Present the plan in chat as one message, then propose each post via
   propose_post so Julie approves them as cards.
4. Send ONE filming ask: the exact clips needed ("30 segundos: corregí
   el teaser, cara a cámara"), batched, 15 minutes total.

## Daily — sweep (when run)
- Summarize new comments/DMs Julie should see; draft replies in her
  voice for approval; never send.
- Flag anything time-sensitive (a question about schedule, a new
  student, a complaint) at the top.
- One growth opportunity found (a post to engage, a collab idea, a
  trend in Pilates/wellness that fits her), or say there is none.

## Friday — report + next drafts
- Followers +/- per account, best and worst post with the numbers,
  which method won, which lost, queue status.
- Two experiments for next week, already drafted, waiting as proposals.
- One honest line: what is NOT working and what you would change.

## Rules for all rhythm tasks
- One consolidated message, not a drip of small ones.
- Numbers come from tools, never from memory.
- End with what you need from Julie — approvals only, listed plainly.
